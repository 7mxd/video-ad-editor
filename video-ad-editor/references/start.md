# البداية — الأدوات، والذوق، والهوية

## قبل أي شي (مرة وحدة بالجلسة)
أول رسالة، بسطرين: «للنتيجة الأقوى: **Opus 5.5** والجهد **max**. يصرف من حدّك أكثر، بس المونتاج يطلع أحسن بوايد.» (Claude Code: `/model opus` ثم `/effort max` · الشات: قائمة الموديل ← Effort ← Max). لا «ultracode» للمونتاج، ولا أرقام صرف أو دقائق.

## الخطوة 0 — جهّز بصمت

`bash scripts/00_setup.sh`
- «كل شي جاهز» ← لا تذكر الموضوع.
- ناقص شي ← قل بجملة شنو راح تنزّل، خذ موافقته، ثم `--install`. فشل؟ الحل بجملة بشرية، بلا لصق الخطأ.
- «الإضافات» فيها «—»؟ اختيارية — اعرضها **مرة وحدة** لما تحتاجها ← `--extras` (كل وحدة ترجع للطريق القديم لو ناقصة).
- «ميزات تحتاج ماك»: طلب وحدة منها؟ قل له من البداية إنها ما تشتغل على جهازه.

مجلد شغل + `scripts/compose.REFERENCE.html` باسم `compose.html`. مقاطع آيفون HDR كثيرة للدمج، أو تنظيف صوت ← `references/setup-tips.md`.

## الخطوة 0.5 — صفحة التعارف

`python scripts/00_onboard.py show` — طبع اختيارات ← `python scripts/00_onboard.py theme <work>` وقل: «ماشي على إعداداتك: ألوان كذا، كابشن كذا.» طبع `{}` ← `references/identity.md` («صفحة التعارف»).
⛔ الصوت المولّد بلا افتراضي: هو يختار (فصحى أو لهجة، رجل أو امرأة). والصوت المولّد ← `references/onboarding.md`.

## الخطوة 1 — هويته البصرية (ما فيه لون افتراضي)

⛔ **لا تفترض الكريمي والطيني** — ذاك ثيم كلود، مو ثيمه.
⛔ **لا تغيّر ثيماً سابقاً.** عنده `theme.json` من قبل؟ استخدمه كما هو. تغيير لون أساسي بطلب صريح منه بس.

0. انكتب `theme.json` بالخطوة 0.5؟ تخطّ.
1. `.auto-memory/creator-profile.md` موجود؟ خذ الألوان والخط والحساب: «راح أمشي بألوانك: كذا وكذا — تمام؟»
2. ما فيه؟ **سؤال واحد:** «شنو ألوان حسابك؟ عطني الخلفية والتمييز وشعارك — أو رابط حسابك، أو كم صورة يعجبك ستايلها.» صور ستايل ← `references/identity.md`.
3. `<work>/theme.json` + شعاره `logo.png`:

```json
{ "bg":"#101828", "ink":"#F5F7FA", "acc":"#F2B33D", "clay":"#C98B18", "mut":"#98A2B3",
  "font":"Tajawal", "handle":"@his_handle", "logo":"logo.png", "grade": false,
  "faceAnchor": 0.30, "badgeUntil": 0, "capStyle": "card" }
```
ألوان بيدك؟ `python scripts/00_onboard.py onacc <work>`. مفاتيح إضافية (`capStill` `bar` `pace` `hookZoom` `outro`…) ← `references/identity.md`.
**⚠️ `outro`:** الافتراضي إعلان السكل نفسه — أي فيديو مو إعلان للسكل لازم يغيّره.
