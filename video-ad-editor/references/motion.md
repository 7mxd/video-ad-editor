# شرح بالموشن — فيلم من نص، بلا تصوير

المدخل: نص، أو فكرة، أو سكربت.
الطريق: صوت (صوته، أو مولّد مجاني) ← فيلم موشن ثلاثي الأبعاد بـ60 فريم.

## الخطوات

1. **البداية:** اقرأ `references/start.md` ونفّذه (الأدوات، الذوق، الهوية).
2. **الوضع:** هالملف — قواعده كلها إلزامية.
3. **الأوامر:** `motion/README.md`، ودليل كاتب المشاهد `motion/ENGINE-API.md`.
4. **شرح موقع أو تطبيق:** قسم «شرح موقع أو تطبيق» تحت + `references/web-app-explainer.md`
5. **ونشوت (فيديو كله لقطة وحدة، بلا قص):** `references/one-take.md` + المثال الشغّال `motion/examples/one-take/`. لإعلان تطبيق أو أداة، أو خطوات، أو فكرة بمشاهد داخل بعض.
5ب. **«اشرح لي شلون يشتغل …» (أي جهاز كآلة ترتسم وتشتغل):** `references/machine-explainer.md` + المثال الشغّال `motion/examples/machine/` (استشوار + مايكرويف). الحقائق من مصدر أول، بعدها الرسم.
6. **أمثلة من الناس (إلهام، مو نسخ):** `references/examples.md`
6ب. **إطار ثابت + جدار شرائح 3D — بطلب المستخدم بس** (مو افتراضي): قسم «لقطة وحدة بإطار ثابت» تحت، والمثال `motion/examples/stage-wall/`.
7. **بنك الحركات — لوحة لكل فيديو (إلزامي):** `references/moves/INDEX.md` (والكود ← `references/moves/code.md`). قبل أول مشهد: `python scripts/35_moves.py plan --title "…"` ← 3 حركات أساسية يدور حولها الفيلم + لهجات للحظات الخاصة، تناديها بـ`ctx.FX.<id>`.

**قواعد الوضع:** ولا رقم أو اسم على الشاشة من برّا `facts.md` ← `references/motion-rules.md`. يشتغل على جهازه عبر Claude Code. بالشات: السكربت والخطة والثيم بس.

## لقطة وحدة بإطار ثابت — بطلب المستخدم بس

⛔ **مو افتراضي ولا لكل فيلم.** استخدمه لما المستخدم يطلبه («إطار ثابت»، «عنوان ثابت وتحته يتبدل»، «جدار شرائح»، «ثري دي»…). بدون طلب: الفيلم يمشي على العصف والفكرة من معنى السكربت مثل العادة.
لما ينطلب، هذي الأدوات:
- **إطار ثابت** (`MOTION.stage`): عنوان فوق ما يتحرك، وتحته خانة تتبدل وتكمّل الجملة (`ctx.text.slot`)، ونافذة المحتوى بالنص. المشاهد والانتقالات تصير داخل النافذة بس.
- **لون أكسنت واحد** على خلفية غامقة، ونفس شكل الكرت بكل المشاهد.
- **جدار شرائح 3D** (`ctx.slideWall`): الكاميرا تطير فوقه وينتهي بكرت يصير أول مشهد بلا قص. أول فريم يبين فيه الجدار (مو شاشة فاضية) لأنه الكفر.
- **موشن بلير** (`motionBlur`): هذا الوحيد اللي ينفع بأي فيلم فيه حركة سريعة — مو شكل، بس يخلّي الحركة ناعمة.
- الألوان كلها من الثيم (`project.palette`) — المثال فاتح، ويشتغل غامق أو بألوان أي عميل بلا تعديل.
- المثال الشغّال: `motion/examples/stage-wall/` — اقراه عشان الطريقة، والفكرة نفسها من معنى سكربتك.

## لا قالب

- اعصف 3 أفكار بنفسك، انقدها، وطوّر الأقوى.
- كل جملة تنشاف بلحظة ما تنقال.

## الرتم

- جملة ≈ مشهد.
- ضربة أو تغيير كل 0.5-1 ث.
- بس أي كلمة على الشاشة تبقى 0.6 ث على الأقل عشان تنقرا.
- لا تقصّ الفراغات لين يصير لاهث.

## الصوت المولّد

الاختيار والتجربة قبل الفيديو الكامل ← `references/onboarding.md`.
- فصحى مشكّلة كاملة — اللهجة بالأصوات المجانية مكسّرة.
- تاء مربوطة آخر الجملة ← «ه» بنص الصوت.
- لا ألف خنجرية.
- الاسم الإنقليزي بحروفه (Opus).
- راجع كل سطر بعينك وبوِسبر medium **قبل** الرسم.
- أرسل له الصوت يسمعه.

يعطيك رابط موقع، أو يقول «اشرح للناس شلون يسوون كذا بالتطبيق».

يصوّر الموقع (شاشات + تمرير + نصوصه وألوانه):

```bash
node scripts/27_web_capture.js <url>
```

```bash
node scripts/31_device3d.js
```
