# تصميم المشاهد (الإضافات والشرح الكامل ← `references/scene-extras.md`)

## البنية جاهزة — لا تلمسها

`compose.html` فيه الأوضاع، الكابشن، ورا الراس، البي-رول، الملصقات، شريط التقدّم، كرت النهاية، والألوان. **افتراضياً بلا مشهد مخصص:** فيديو ملء الشاشة + كابشن + كرت النهاية.

## شلون تكتب مشهدك

مشاهدك بآخر `compose.html`، بسكربت ثاني تحت سكربت المحرّك:

```html
<script>
SCENES=[{s:0,e:4.1,m:R_FULL},{s:4.1,e:9.8,m:R_DOWN,gb:480},{s:9.8,e:99,m:R_FULL}];
/* 9.8 = آخر كلمة بالجملة + 0.45 (references/motion-rules.md §3) */
function listPanel(t){
  if(t<4.1||t>9.8) return;
  panelIn(t,4.1,9.8,()=>{ /* رسم بإحداثيات 130..950 × 278..458 */ });
}
SCENE_LIST.push(['listPanel',listPanel]);   // بدون التسجيل ما ينرسم
</script>
```

- كل مشهد يلتصق بتوقيت الكلمة من `caps.json` (`wordsOf(i)` = كلمات الجملة i من صفر) — لا بتوقيت تقريبي.
- على صورة الفيديو نفسها (قليتش): `SCENE_LIST.push(['myFx',myFx,'video'])`. `SCENES` تقدر تكتبها بـ`studio.json` بدال الكود.
- من الاستوديو: `studio.json` ← `"sceneFx":["listPanel"]` يسجّل بالاسم.
- `[compose] ⚠️ مشهد متخطّى` = مشهد طاح — صلّحه. أمثلة: `scripts/compose.EXAMPLES.js`.

**حزمة الموشن** (`scripts/motion-kit.js`: عدّاد، بطاقات أرقام، منحنى، أعمدة، تايملاين، ختم…) بكل فيديو فيه أرقام أو شرح ← اقرأ `references/motion-kit.md` قبل التصميم.

## الفكرة — استعارة بصرية، مو زينة

اعصف 3-4 أفكار لكل جملة. الفكرة **تمثّل اللي يقوله**:

يعدّد ← بطاقات تنقلب بصح · رقم ← عدّاد ينزل بضربة · «انكسر» ← قليتش وشقوق · مشكلة ثم إصلاح ← تحذير ثم تقدّم.
الجدول أمثلة، مو قالب. **اخترع جديد كل مرة.**

## تفاصيل التخطيط

- `R_DOWN` كرت مرن يصغر حسب أسفل الرسم (`gb`) وأسطر الكابشن؛ `panelIn()` تتكبّر 1.2 وحدها.
- **قاعدة المستخدم:** أي جملة الموشن يكتب كلامها على الشاشة = `nocap` لنفس الجملة (`{s,e,m,nocap:true}`) — كابشن تحت + نص فوق = «أقرا فوق ولا تحت؟».
- الموشن الكتابي يفضّل الفاضي **فوق الراس** (تفضيل). نص لازم يبين **قدّام** الشخص المقصوص ← `MV.scene('x',fn,'afterPerson')` أو `window.AFTER_PERSON`.
- **اختيار الوضع قرارك من معنى الكلام** — لكل جملة: الوجه أهم ولا الرسمة؟ انفعال ← الوجه · أرقام وشرح ← `R_LOWER`/`R_OFF` · تعليق على رسمة ← `R_DOWN`. الثابت بس: الكابشن ما ينكتب على الوجه، والمنطقة الآمنة.

بي-رول، شعار 3D (⛔ بطلبه بس)، شبكة الخلفية، والشرح الكامل ← `references/scene-extras.md`.
