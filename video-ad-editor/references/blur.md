# بلر الخصوصية — أي شي يسمّيه المستخدم

المستخدم يقول بكلامه وش ينخفي (رمز QR، باركود، رقم تسلسلي، وجه، لوحة سيارة، شاشة، ورقة…). `scripts/blur_track.py` يلقاه بروحه، يتتبّعه، ويبلّره على `cut.mp4` **قبل** ما المحرّك يرسم الطبقات — فكل الأوضاع تاخذه. يحتاج opencv ونموذج الوجوه: ناقصين؟ ← `bash scripts/00_setup.sh --extras`.
⛔ **الجلسة الرئيسية ما تفتح أي صورة.** الصور (لقطات، ورقة الفحص، فيديوهات مرجعية) للـsubagent (Sonnet) بس، ويرد بسطر أو JSON.

## 0. قسّم الطلب

| اللي طلبه | الطريق |
|---|---|
| `qr` · `barcode` · `face` | **أ** — `detect`، كشف تلقائي بلا توكنز |
| أي شي ثاني (رقم تسلسلي، رقم شهادة، لوحة، شاشة، شعار، رقم بيت…) | **ب** — `keyframes` ← subagent ← `boxes` |
| خليط | الاثنين: الأول بدون `--add`، والثاني بـ`--add` |

- شي حول الكود (ملصق كامل حول باركود) = طريق ب، والكود نفسه طريق أ — الاثنين ينبلّرون.
- **فيديوهات مرجعية (اختياري):** subagent يشوف فريم أو فريمين منها ويرد بسطر: وش انبلّر وقوّة البلر تقريباً. يحدّد `--strength` ووش تسمّي بس — ما يغيّر الأوامر.
- اسم ملف بلا مسار (`cut.mp4`، `boxes.json`، `qa.jpg`) = داخل `<work>`.

## 1. الطريق أ — كشف تلقائي

```
python scripts/blur_track.py detect <work> cut.mp4 --kinds qr,barcode,face [--from 3 --to 9] [--add | --replace]
```
- كل نسخة = هدف برقمه (ثلاث باركودات = ثلاث أهداف). اختفى ورجع خلال ثانية = نفس الهدف، بعدها هدف جديد.
- `ما لقيت: X` ← مو بالفيديو أو ما انكشف. المستخدم متأكد إنه موجود؟ ← طريق ب له.
- `⚠️ نموذج الوجوه ناقص` ← الوجوه بطريق ب (أو `00_setup.sh --extras`).
- `blur.json` فيه أهداف وما حطّيت `--add`/`--replace` ← يرفض (خروج 2) وما يمسح شي.

## 2. الطريق ب — اللي ينوصف بالكلام

```
python scripts/blur_track.py keyframes <work> cut.mp4 [--every 2] [--max 12]
```
يطلّع ≤ 12 لقطة (كل ~2ث + كل قطع مشهد، ضلعها الطويل ≤ 720) بـ`<work>/kf/` مع `keyframes.json` (الوقت لكل لقطة).
أرسل لـsubagent (Sonnet) مسار `kf/` والقائمة اللي سمّاها المستخدم، بهالبرومبت كما هو:
> «بالصور اللي بـ`<work>/kf/` (وقت كل صورة بـ`keyframes.json`): حدّد **بس** هالأشياء: <القائمة>. لا تحدّد أي نص ثاني (مثل اسم العملة أو الدرجة). رد بـJSON بس، بلا أي شرح:
> `{"items":[{"id":"<الشي>-<رقم>","t":<الوقت بالثواني>,"box":[x,y,w,h]}],"not_found":["<شي ما لقيته>"]}`
> الإحداثيات بالبكسل على الصورة نفسها. نفس الشي بأكثر من صورة = نفس الـid. المربع يغطي الشي كامل مع هامش بسيط.»

احفظ الرد بـ`<work>/boxes.json`، ثم:
```
python scripts/blur_track.py boxes <work> cut.mp4 boxes.json [--add]
```
- كل `id` = هدف (يطبع «هدف N = id»). `ما لقيت: X` من `not_found` — قله للمستخدم بجملة.
- وقت برّا الفيديو أو مربع برّا الفريم ← خروج 2 باسم الـid، و`blur.json` ما يتغيّر.

## 3. السطر — اقراه بالأرقام

```
نوافذ 2 · فريمات 214 · غير مؤكد 9 · مفقود>1ث 0
```
- **نوافذ:** كم مقطع متصل فيه هدف. **فريمات:** كم فريم بيتبلّر.
- **غير مؤكد:** ثقة قليلة (البلر توسّع 1.5×) أو الهدف ضاع ≤ 1ث (آخر مكان معروف، موسّع 2×). الخصوصية تغلط على زيادة البلر.
- **مفقود>1ث:** مدى ضاع فيه الهدف أكثر من ثانية.

النتيجة بـ`<work>/blur.json` (المضلعات والثقة والحالة لكل فريم: `tracked` · `widened` · `held` · `lost`).

## 4. الخروج بـ3 = لا تكمل

لو `مفقود>1ث` أكبر من 0، السكربت يطلع بـ3 ويطبع المدى، و`apply` **يرفض** يرسم — عشان ما يطلع فيديو فيه فجوة بلا بلر. قل للمستخدم المدى بجملة، وخيّره:
1. يحدّد الهدف من جديد بهالمدى ← `box … --target رقمه` بثانية داخل المدى (الرقم بالرسالة «هدف N») — الأحسن.
2. أو يوافق على شريط بعرض الفريم كامل لهالمدى ← `apply … --accept-band` (الشريط على صفوف آخر مكان معروف لنفس الهدف؛ هدف ما له مكان معروف = الفريم كله).

`apply` و`qa` يطلعون بـ3 بعد لو الفيديو مو نفسه اللي انتتبّع (المقاس أو fps أو عدد الفريمات) — تتبّع من جديد على هالفيديو.

## 5. طبّق البلر

```
python scripts/blur_track.py apply <work> cut.mp4 cut_blur.mp4
```
بلر داخل المضلع بس، والباقي بنفس بكسلاته (ولا تعديل لوني)، والصوت ينسخ مثل ما هو. كمّل المسار بـ`cut_blur.mp4` بدل `cut.mp4`.
- قوة البلر `--strength 31` بالبكسل وما تتغير مع المقاس: هدف كبير بفيديو 1080×1920 ← ارفعها (61 مثلاً).
- HDR: بلّر `cut.mp4` (SDR بعد محوّل 03)، مو ملف آيفون HDR خام — يطلع 8-بت.

## 6. فحص بصري — ورقة وحدة بـsubagent

```
python scripts/blur_track.py qa <work> cut_blur.mp4 qa.jpg
```
الورقة (24 لقطة بالكثير، مكتوب عليها الوقت والحالة، والمضلع بالأحمر): 6 لقطات `clear` بلا بلر (عشان شي فات الكشف)، أول وآخر فريم بكل نافذة، والفريمات غير المؤكدة.
أرسل `qa.jpg` لـsubagent (Sonnet) مع هالسؤال بس:
> «الأشياء المطلوب إخفاؤها: <القائمة>. بكل لقطة: هل باين أي واحد منها ينقرا، داخل الخط الأحمر أو حوله، أو بلقطات `clear`؟ رد بـOK، أو بأوقات اللقطات اللي فيها مشكلة ووش الشي.»

- رد **OK** ← كمّل.
- رد بأوقات ← **جولة تصليح وحدة بس:** هدف موجود ← `box … --target رقمه`؛ شي فات ← `box … --add` (أو `keyframes`/`boxes --add`)، ثم `apply` و`qa` مرة وحدة.

لا تفحص كل نص ثانية بالصور — الأرقام أولاً، وورقة وحدة.

## 7. تحديد يدوي (لما الكشف ما يكفي)

| الحالة | الأمر |
|---|---|
| شي **يتكرر** وعندك صورته (ملصق بنفس التصميم، كرت، شهادة) | `ref` — صورة مرجع + المنطقة بالكسور (0–1) من الصورة |
| شي تشوفه بفريم معيّن | `box` — مربع بالبكسل على فريم ثانية معيّنة، ويتتبّعه قدّام وورا |

```
python scripts/blur_track.py ref <work> cut.mp4 label.jpg 0.10,0.62,0.90,0.80 [--from 3 --to 9]
python scripts/blur_track.py box <work> cut.mp4 4.2 610,880,260,90 [--from 3 --to 9]
```
- هدف ثاني ← `--add`؛ تحديد من جديد لنفس الهدف ← `--target رقمه` (يشيل مدى هالهدف المفقود بس لو غطّاه كامل)؛ من الصفر ← `--replace`.
- إحداثيات المربع: فريم واحد (`ffmpeg -ss 4.2 -i cut.mp4 -frames:v 1 f.jpg`) يقراه **subagent (Sonnet)**، مو الجلسة الرئيسية.
