# الأسلوب: ريل متكلم (talking-head)

**متى:** كلام للكاميرا يغطي أغلب المدة — ريل أو إعلان أو فيديو بالعرض.
**الخطوات:** `references/reel.md` كما هي. هذي افتراضياتها؛ البطاقة تغلبها.

## القص
- `python scripts/01_cut_plan.py <work>` — قل له كم انشال: «شلت 52 ثانية سكوت — الفيديو صار 46 بدل 98.»
- `python scripts/03_cut_zoom.py <work>` — زوم كل مقطع مقفول بـ`cut.json` ← `"zooms"`.
- **متحدث هادي متعمّد** (قرآن، موعظة): «أخلي السكتات؟» وافق ← `cut.json` ← `"keep":[[0,المدة]]`.

## الترجمة (افتراضي: on)
- صحّح كل جملة بـ`a.json` (وِسبر يغلط بالعامية) ← `<work>/fixes.json`، ثم `python scripts/02_captions.py <work>`.
- ⛔ **عدد كلمات كل جملة = عدد كلمات وِسبر لنفس الجملة.** وإلا تختل التوقيتات.
- ⛔ **الكابشن ما ينكتب على وجه المتحدث أبداً.**
- **وأول كابشن يبان بأول نص ثانية.**
- `python scripts/09_srt.py <work> ad-master` ← `.srt` لليوتيوب ولينكدإن، و`.txt` = نص كلامه لكابشن البوست.
- البطاقة: `on` ← كابشن على الفيديو + `.srt` · `off` ← `.srt` بس، بلا كابشن على الفيديو · `both` ← نسختين (بكابشن وبلا) + `.srt`.

## الإيقاع والتخطيط
| اللحظة | المستطيل |
|---|---|
| كلام بلا رسم | `R_FULL` |
| أي رسم أو موشن | `R_DOWN` |
| بي-رول أو لوحة كبيرة | `R_LOWER` |
| شرح كامل (أرقام، قوائم) | `R_OFF` |
- بدون ما يطلبه، الإيقاع يبقى العادي. «بإيقاع هادي» ← `references/explainer-and-pace.md`.
- **الهوك فيه حركة بأول ثانية.**
