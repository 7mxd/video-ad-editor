## 4) التفريغ بتوقيت الكلمة

```bash

python scripts/transcribe.py <work> > <work>/whisper.log 2>&1
```

الخطوة 0 سوّت `a.wav` و`a.json`؟ ينعادون بس لو تغيّر `src.mov` (3.5). وإلا دقايق — بالخلفية، وقل له كم يتوقع. فشل؟ `tail -5 <work>/whisper.log`

**4.1) ⛔ افحص التفريغ قبل التصحيح — إلزامي:**

## 5) التصحيح والكابشن

صحّح كل جملة بـ`a.json` (وِسبر يغلط بالعامية) ← `<work>/fixes.json`، ثم `python scripts/02_captions.py <work>`:

```json
{ "fix": [["كل","شي","تشوفه"], ["الكابشن","الزوم"]], "hot": ["تشوفه","الزوم"], "fx": {"خلاص":"drop"} }
```
- `hot` = كلمات تنحبس بقرص التمييز. `fx` اختياري ← `references/word-fx.md`
- ⛔ **عدد كلمات كل جملة = عدد كلمات وِسبر لنفس الجملة.** وإلا تختل التوقيتات.

## 5.5) اعرض عليه النص، وشيل اللي ما عجبه ← إلزامي قبل أي مشهد

`python scripts/10_script_edit.py <work> show` — مرقّم بالتوقيت + الجمل المعادة (لا تشغّل `dupes` بعده).
- ⛔ **اطبع السكربت كامل بالشات** وقل: «شنو تبي أشيل؟» — لا تكتفِ بالملف.
- الجملة المعادة: الأولى غلط والثانية التصحيح — «قلت الجملة مرتين — ‹…› ثم ‹…›. أشيل الأولى؟»
- `drop 6 8` · `keep 1 2 5 9` · `undo`. **سوّها هني**: الحذف بعد المشاهد يزيح أوقاتها. بعد أي حذف: أعد الخطوة 6، والرسم بـ`--force`.

## 7) صمّم المشاهد ← أهم خطوة

**قبل أي مشهد اقرأ:** `references/motion-rules.md` (الهوية، `facts.md`، الممنوعات، لوحة الحركات) ← `references/scenes.md` ← `references/moves/INDEX.md` (بنك الحركات) ← `references/styles.md`.

**🎯 الأصل من أول مسودة (6.0 — ريل بوبيان):** تتعب على الأداء والموشن — غني وعميق ويفاجئ، مو أشياء هادية.
- قبل الرسم خطّط **2–3 لحظات عمق** وقلها بسطر (ورا راسه، موجة صوته، خريطة، مدار 3D، شكل من هوية العميل، دخلة ون تيك) ← `references/moves/depth.md`. البطاقات والأختام **مو ممنوعة** لما الموضوع يستاهل.
- **⛔ العنصر ما يختفي مع آخر كلمة** — `e = آخر كلمة + 0.45` (`references/motion-rules.md` §3).

**⛔ قاعدة التخطيط (معتمدة من المستخدم):**

| اللحظة | المستطيل | الشكل |
|---|---|---|
| كلام بلا رسم | `R_FULL` | وجهه ملء الشاشة، أسفل الكابشن عند 1460 |
| أي رسم أو موشن | `R_DOWN` | الرسم فوق (y 280-520) ← الكابشن ← وجهه تحت بعرض الشاشة |
| بي-رول أو لوحة كبيرة | `R_LOWER` | الكرت الكبير فوق ← الكابشن ← وجهه صغير تحت |
| شرح كامل (أرقام، قوائم) | `R_OFF` | بلا وجه، صوته يكمّل ← `references/explainer-and-pace.md` |

- ⛔ **الكابشن ما ينكتب على وجه المتحدث أبداً.** بأي وضع فيه كرت، الكابشن كله فوق الكرت، وشريط التقدّم معه.
- **⛔ المنطقة الآمنة** (`08_safe_check.js` يفحصها) — لا نص بـ: أعلى y 0-150 · أسفل y 1620-1920 (حزام حذر 1500-1620) · يمين x 950-1080 بين y 1100 و1750. **وأول كابشن يبان بأول نص ثانية.**
