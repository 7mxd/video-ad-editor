# بلر الخصوصية — رقم، شاشة، ورقة، لوحة، وجه

السكربت `scripts/blur_track.py` يتتبّع اللي تبي تخفيه ويبلّره على `cut.mp4` **قبل** ما المحرّك يرسم الطبقات — فكل الأوضاع تاخذه (ريل، مونتاج، …). يحتاج opencv: ناقص؟ ← `bash scripts/00_setup.sh --extras`.
الكشف التلقائي للوجوه واللوحات مو موجود: المستخدم يحدّد الهدف مرة وحدة.

## 1. حدّد الهدف — `ref` ولا `box`؟

| الحالة | الأمر |
|---|---|
| شي **يتكرر** وعندك صورته (ملصق بنفس التصميم، كرت، شهادة) | `ref` — صورة مرجع + المنطقة بالكسور (0–1) من الصورة |
| شي يبان بالفيديو بس (شاشة، ورقة، لوحة، وجه) | `box` — مربع بالبكسل على فريم ثانية معيّنة، ويتتبّعه قدّام وورا |

```
python scripts/blur_track.py ref <work> cut.mp4 label.jpg 0.10,0.62,0.90,0.80 [--from 3 --to 9]
python scripts/blur_track.py box <work> cut.mp4 4.2 610,880,260,90 [--from 3 --to 9]
```
- اسم ملف بلا مسار (`cut.mp4`، `cut_blur.mp4`، `qa.jpg`) = داخل `<work>`.
- `--from/--to` (ثواني) لما الهدف يبان بجزء من الفيديو بس — برا النافذة ما يتبلّر شي.
- هدف ثاني ← نفس الأمر مع `--add` (ياخذ رقم هدف جديد، والقديم يبقى). بدونه و`blur.json` فيه أهداف ← يرفض (خروج 2) وما يمسح شي؛ تبدأ من الصفر فعلاً ← `--replace`.
- تحديد من جديد لنفس الهدف ← `--target رقمه`: يشيل مدى هالهدف المفقود بس لو غطّاه كامل. هدف ثاني ما يشيل مدى غيره أبداً.
- المربع: افتح فريم واحد (`ffmpeg -ss 4.2 -i cut.mp4 -frames:v 1 f.jpg`) واقرأ الإحداثيات منه — **بـsubagent (Sonnet)**، مو بالجلسة الرئيسية.

## 2. السطر — اقراه بالأرقام

```
نوافذ 2 · فريمات 214 · غير مؤكد 9 · مفقود>1ث 0
```
- **نوافذ:** كم مقطع متصل فيه الهدف. **فريمات:** كم فريم بيتبلّر.
- **غير مؤكد:** فريمات ثقتها قليلة (البلر توسّع 1.5×) أو الهدف ضاع ≤ 1 ث (آخر مكان معروف، موسّع 2×). الخصوصية تغلط على زيادة البلر.
- **مفقود>1ث:** مدى ضاع فيه الهدف أكثر من ثانية.

النتيجة بـ`<work>/blur.json` (المضلعات والثقة والحالة لكل فريم: `tracked` · `widened` · `held` · `lost`).

## 3. الخروج بـ3 = لا تكمل

لو `مفقود>1ث` أكبر من 0، السكربت يطلع بـ3 ويطبع المدى، و`apply` **يرفض** يرسم — عشان ما يطلع فيديو فيه فجوة بلا بلر. قل للمستخدم المدى بجملة، وخيّره:
1. يحدّد الهدف من جديد بهالمدى ← `box … --target رقمه` بثانية داخل المدى (الرقم بالرسالة «هدف N») — الأحسن.
2. أو يوافق على شريط بعرض الفريم كامل لهالمدى ← `apply … --accept-band` (الشريط على صفوف آخر مكان معروف لنفس الهدف؛ هدف ما له مكان معروف = الفريم كله).

`apply` و`qa` يطلعون بـ3 بعد لو الفيديو مو نفسه اللي انتتبّع (المقاس أو fps أو عدد الفريمات) — تتبّع من جديد على هالفيديو.

## 4. طبّق البلر

```
python scripts/blur_track.py apply <work> cut.mp4 cut_blur.mp4
```
بلر داخل المضلع بس، والباقي بنفس بكسلاته (ولا تعديل لوني)، والصوت ينسخ مثل ما هو. كمّل المسار بـ`cut_blur.mp4` بدل `cut.mp4`.
- قوة البلر `--strength 31` بالبكسل وما تتغير مع المقاس: هدف كبير بفيديو 1080×1920 ← ارفعها (61 مثلاً).
- HDR: بلّر `cut.mp4` (SDR بعد محوّل 03)، مو ملف آيفون HDR خام — يطلع 8-بت.

## 5. فحص بصري — ورقة وحدة بـsubagent

```
python scripts/blur_track.py qa <work> cut_blur.mp4 qa.jpg
```
الورقة فيها الفريمات غير المؤكدة وأول وآخر فريم بكل نافذة بس (24 لقطة بالكثير، مكتوب عليها الوقت والحالة، والمضلع بالأحمر).
⛔ **لا تفتح `qa.jpg` بالجلسة الرئيسية.** أرسله لـsubagent (Sonnet) مع هالسؤال بس:
> «بكل لقطة: هل باين أي رقم أو نص أو وجه ينقرا داخل الخط الأحمر أو حوله؟ رد بـOK، أو بأوقات اللقطات اللي فيها مشكلة.»

- رد **OK** ← كمّل.
- رد بأوقات ← حدّد الهدف من جديد حولها (`box … --target رقمه`، أو `--add` لو شي ثاني)، ثم `apply` و`qa` مرة وحدة بس.

لا تفحص كل نص ثانية بالصور — الأرقام أولاً، وورقة وحدة.
